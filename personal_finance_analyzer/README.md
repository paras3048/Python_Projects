# Personal Finance Analyzer

A command-line Python application that allows users to record their income and expenses and analyze their personal financial activity.

The application processes transactions using Pandas and NumPy and generates financial summaries and visualizations using Matplotlib.

No external dataset, API, or online service is required.

## Features

* Record income and expenses
* Categorize expenses
* Record payment methods
* Add transaction dates
* Calculate total income
* Calculate total expenses
* Calculate savings
* Calculate savings rate
* Determine financial status
* Analyze spending by category
* Analyze spending by payment method
* Analyze monthly income and expenses
* Identify the largest expense
* Generate financial charts
* Export the complete analysis to CSV

## Technologies Used

* Python
* Pandas

## Installation

Make sure Python is installed.

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

## Running the Project

Run the following command:

```bash
python main.py
```

The program will ask you to enter your financial transactions.

## Visualizations

The program generates three visualizations.

### 1. Expenses by Category

A bar chart comparing how much money was spent in each category.

### 2. Monthly Income vs Expenses

A bar chart comparing income and expenses across different months.

### 3. Expense Distribution

A pie chart showing the percentage of total expenses represented by each category.

## Financial Calculations

### Savings

```text
Savings = Total Income - Total Expenses
```

### Savings Rate

```text
Savings Rate = (Savings / Total Income) × 100
```

A positive savings value indicates a surplus, while a negative value indicates that expenses exceeded income.
