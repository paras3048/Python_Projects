# Student Performance Analytics System

A command-line Python application that collects student marks and performs basic academic performance analysis.

The project takes student information directly from the user, processes the data using Pandas and NumPy, and generates statistical summaries and visualizations using Matplotlib.

No external dataset or API is required.

## Features

* Enter multiple students
* Enter marks for multiple subjects
* Automatically calculate:

  * Total marks
  * Average marks
  * Percentage
  * Grade
  * Pass/Fail result
* Identify the class topper
* Calculate class-level statistics
* Calculate subject-wise statistics
* Identify the strongest and weakest subject
* Display grade distribution
* Generate performance charts
* Export the final analysis to a CSV file

## Technologies Used

## Installation

Make sure Python is installed.

Create a virtual environment if desired:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

## Running the Project

Run:

```bash
python main.py
```

The program will ask for the student's name and marks.

Example:

```text
Enter student name (or 'done' to finish): Rahul
Enter marks for Maths: 85
Enter marks for Physics: 78
Enter marks for Computer Science: 92

Enter student name (or 'done' to finish): Aman
Enter marks for Maths: 72
Enter marks for Physics: 81
Enter marks for Computer Science: 75

Enter student name (or 'done' to finish): done
```

## Analysis Performed

After entering the data, the program calculates individual student performance.

Example:

```text
Name    Maths   Physics   Computer Science   Total   Average   Grade   Result
Rahul   85      78        92                 255     85.00     A       Pass
Aman    72      81        75                 228     76.00     B       Pass
```

It also calculates class statistics such as:

```text
Number of students : 2
Class average      : 80.50
Highest average    : 85.00
Lowest average     : 76.00
Students passed    : 2
Students failed    : 0
Pass percentage    : 100.00%
```

## Grade System

The application uses the following grading system:

| Percentage | Grade |
| ---------: | :---- |
|     90–100 | A+    |
|      80–89 | A     |
|      70–79 | B     |
|      60–69 | C     |
|      50–59 | D     |
|      40–49 | E     |
|   Below 40 | F     |

A student must score at least 40 in every subject to pass.

## Visualizations

The program generates three charts:

### 1. Average Marks by Subject

Shows the average performance of the class in each subject.

### 2. Student Average Performance

Compares the average marks of individual students.

### 3. Grade Distribution

Shows the percentage of students receiving each grade.

## Output File

After analysis, the program automatically creates:

```text
student_performance.csv
```

This file contains the processed student data.

The CSV is generated by the program itself, so no external dataset is required.
